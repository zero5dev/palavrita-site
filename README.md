# palavrita-site

Página pública do app **Palavrita** (zero5), publicada pelo GitHub Pages.

- `index.html`: apresentação do app.
- `privacidade.html`: política de privacidade (URL informada no Play Console).
- `icone.png`: ícone do app (gerado por `app/tools/gerar_icones.py` no repositório do app).

Publicação: *Settings → Pages → Deploy from a branch → `main` / root*. Endereço esperado:
`https://zero5dev.github.io/palavrita-site/privacidade.html`.
